# Mastering-AI-Agents-Workshop

1. pip install requests beautifulsoup4 streamlit langchain_ollama

2. ollama pull mistral
ollama run mistral


3. streamlit run ai_scraper_app.py


| **Package**        | **Why it's needed**                                       |
| ------------------ | --------------------------------------------------------- |
| `requests`         | To make HTTP requests and fetch HTML from the URL         |
| `beautifulsoup4`   | To parse and extract text content from the HTML           |
| `streamlit`        | To build and display the web interface                    |
| `langchain_ollama` | To access Ollama LLM models like `mistral`, `llama3`, etc |
