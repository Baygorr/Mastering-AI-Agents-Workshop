# 🤖 Basic AI Agent with Memory & Web UI

This project is a minimal conversational AI chatbot built with:

- 🧠 [LangChain](https://www.langchain.com/)
- 💬 [Ollama](https://ollama.com/) for running local LLMs (e.g., Mistral, LLaMA3)
- 🌐 [Streamlit](https://streamlit.io/) for a clean and simple Web UI


## 🚀 How to Run (Quick Guide)

1. pip install streamlit langchain langchain-core langchain-community langchain-ollama
2. After installation, open a terminal and run:
ollama pull mistral
ollama run mistral
3. streamlit run basic_ai_agent.py
